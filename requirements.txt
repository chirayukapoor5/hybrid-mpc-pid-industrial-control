# Benchmark notes and experimental evaluation

## Objective

The project compares a standard PID controller, a model-predictive controller, and a hybrid controller in which MPC contributes a predictive feedforward term to the PID feedback loop.

## Experimental scenarios

The benchmark covers:

1. Setpoint step
2. Inflow disturbance rejection
3. Actuator saturation
4. Model mismatch
5. Solver failure / fallback behavior
6. Different prediction horizons

## Recorded metrics

The project records the following quantities:
- integral absolute error (IAE)
- overshoot
- settling time
- count and magnitude of constraint violations
- mean, 95th percentile, and maximum execution time
- peak memory usage
- solver iteration count
- percentage of time MPC is active

## Interpretation

The hybrid PID + MPC feedforward architecture should generally yield a better trade-off than pure PID or pure MPC in resource-constrained settings. PID retains robustness and simplicity, while MPC improves anticipatory correction under dynamic or constraint-heavy conditions.

## Important caveat

Observed benchmark timing on a laptop or desktop cannot be used as a proof that the controller is suitable for real-time ABB deployment. A valid real-time claim requires a target hardware analysis and worst-case timing evaluation, not just average timing.
